# Agents Documentation

This document outlines the purpose and usage of the Memory Bank and other documentation within this project.

## Rules

Check the `.clinerules` directory to find the must follow rules and general information.

## Memory Bank

The Memory Bank, located in the `memory-bank/` directory, serves as the central repository for all project context, technical decisions, and ongoing progress. It is crucial for understanding the project's history, current state, and future direction.

## README.md

The `README.md` file provides a high-level overview of the project, including setup instructions, available scripts, and a brief architectural summary. It is the primary entry point for new contributors.

## Development Workflow

Our AI-assisted workflow uses:

- **Memory Bank** for project context
- **Plans** for technical implementation blueprints

## Documentation Workflow

- **Referencing**: Always refer to the Memory Bank for in-depth information.
- **Updating**: Keep the Memory Bank updated with new insights, decisions, and progress.
- **Consistency**: Ensure consistency between `README.md` and the Memory Bank.
